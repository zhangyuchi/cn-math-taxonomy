# PDF 试卷自动结构化与文件大小策略

- 日期：2026-11-06；Task Mode：`design-build`；状态：已实现并验证，advisor 开工/终审均 GO；Outcome Status：`complete`。
- 目标：取消原有 1 MiB 源文件门槛，扫描卷无需人工改写 Markdown 即生成待审题目；最终由 advisor 终审并推送 `feat/import-module`。

后续契约覆盖：本文记录交付时的 null 挂点路径；当前试卷挂点规则以[强制挂点设计](2026-11-06-forced-topic-match.md)为准，每题自动选择同学科最佳现有知识点，报告供复核可改。

## 证据与边界

开工时分支 `feat/import-module`，工作区干净。`store.py` 对所有源文件限制 1 MiB；`ocr.py` 复用此限制；`ocr_mineru.py` 另对单段与合并 Markdown 限制 1 MiB；`api.py` 限制请求 2 MiB；CLI 在校验前读取完整文件。`paper.py` 只接收英文键值的题目块或 CSV，扫描结果缺少这些键时返回 `EMPTY_PAPER`。`revision.py` 另对入站草稿修订限制 1 MiB。

证据来自上述代码、现有测试及使用指南，仅证明当前实现；尚无本轮真实 MinerU 识别准确率证据。用户允许用夹具证明扫描卷自动进入 `needs_review`。qqvps 继续禁用重 OCR，不在本轮部署范围。

## 决策与逻辑链

| ID | 因为 | 所以 |
|---|---|---|
| LC-1 | PDF 及 OCR 产物通常大于原 1 MiB 门槛；当前实现使用内存缓冲 | 按类型设置有限上限，并同步 HTTP、CLI、适配器与回读，保留有界内存防护 |
| LC-2 | OCR 输出已有印刷题号、选项和答案，但不含导入字段 | 在 OCR 与现有 draft 转换之间增加自动结构解析，不要求教师整理格式 |
| LC-3 | 未知答案、歧义题号及已删除的临时题图不能可靠自动还原 | 不臆造内容，保留结构诊断并返回专用失败码；审核只处理业务决策 |
| LC-4 | 自动解析不等于知识归属正确或正式数据合规 | 保留 `topicId:null`、挂点建议、审批摘要与原 validator/apply 门禁 |

选择确定性的本地结构解析，复用现有题 schema，无新增外部服务或模型依赖。拒绝“仅提高上限”及“让用户整理 MD”，均不能满足自动化目标。拒绝无界缓冲；对已经限量的文件无须新增流式上传协议。未要求生成原卷不存在的答案。

## 详细契约

- 一个轻量限制模块为唯一数值来源：文本 16 MiB、PDF 64 MiB、OCR 输出（单段和合并）64 MiB、入站草稿修订 64 MiB、HTTP 请求 65 MiB（容纳 multipart/JSON 元数据）。文本较小以约束解析缓冲，PDF/OCR 放宽以容纳扫描卷与较长公式；仍为内存实现，不承诺无限大文件。
- 源文件创建及 CLI/worker 回读都按类型检查；有界读取最多 `limit+1` 字节。超过上限仍为 `SOURCE_SIZE`/413；HTTP 超限为 `REQUEST_TOO_LARGE`/413；OCR 非法/超限为 `OCR_OUTPUT_INVALID`。修订保持原错误类别。
- PDF paper 路径：原始 PDF → HOME MinerU 插件 → OCR Markdown → 自动切题及答案对齐 → 现有题 schema → 完整报告与 `needs_review`。保留 OCR 原文；结构化结果在 `draft/questions.json`，证据在 `reports/parse.json`。
- 支持普通数字题号、Markdown 标题、中文大题分节、同行/分行 A–D 选项、中文答案/解析标签和卷末编号答案（包括 Markdown 及简单 HTML 表格）。保留数学公式和子题文本。英文键值结构化插件输出保持兼容。
- 答案以原文显式内容为依据；类型按选项和答案形态推断为 `choice`/`numeric`/`short`，未指定难度默认 `standard` 并在报告标识。挂点未指定时保留 null，仅提供同学科建议。
- 原始题号/分节用于对齐；重复或冲突、缺答案、无法切题、临时题图引用不完整时不得把失败变成待审格式整理任务。返回明确的结构失败、答案缺失或资源缺失错误，保留诊断。失败任务可在引擎/解析器修复后 requeue 同一源；不要求用户修改 MD。
- 已有结构化 MD/TXT/CSV 行为兼容，原 `EMPTY_PAPER` 仅保留文本路径语义。不修改正式数据或自动批准新题。
- 不新增并发、持久化迁移、凭据或外网连接；沿用单 worker、全库→job 锁、OCR 整组超时终止、临时目录清理、审批摘要和可恢复 apply。
